## 失败矩阵（Phase B 输入）

| 优先级 | 影响 | 失败检查 | 当前缺口 | 下一窗口最小验收 |
|---|---|---|---|---|
| **P0** | 高 | `collect_chunk_evidence_relevance / top_chunk_stable_locator` | chunk 有 `knowledge_id`、`chunk_id/index`、文本和 URL，但没有 Agent 可直接消费的统一 `citation_locator` | 每条 chunk 证据返回稳定 locator，并能唯一定位到来源与片段 |
| **P1** | 高 | `find_bridges_partial_contract / bridge_evidence_trace` | 桥接候选有分数、相邻节点和关系类型，但没有逐跳 `evidence_path`，分数无法直接核验 | candidate 返回用于 bridge score 的最小关系边/路径证据 |
| **P1** | 高 | `timeline_partial_contract / timeline_item_locator` | 时间点公开时间字段/来源，但没有回到原文的统一 locator | timeline point 返回 source 与稳定 locator，可核验时间值出处 |
| **P1** | 中 | `contrast_partial_contract / contrast_dimension_provenance` | shared/only/relation signals 有聚合结果，但缺少“维度 → 候选/来源”的 provenance 映射 | 每个对比维度返回最小来源映射，支持逐项引用 |

## 已验证的当前稳定契约

- 多跳子图、关系过滤、直接/两跳/不可达解释结果正确
- 参数上限 clamp 与空值/非法排序验证可观察
- chunk 命中相关性与 `chunk_id/index` 输出稳定
- chunk `no_hits`、`path_unavailable`、`search_error` 三种状态可区分
- 路径不可用与异常均回退文档级证据，并返回结构化 `chunk_degraded[reason]`
- 三个 partial Tool 均返回 `implementation_level=partial`、`limitation_notes` 和 `evidence_sources`
