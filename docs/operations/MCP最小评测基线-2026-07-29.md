## 已验证的当前稳定契约

- 多跳子图、关系过滤、直接/两跳/不可达解释结果正确
- 参数上限 clamp 与空值/非法排序验证可观察
- chunk 命中相关性与 `chunk_id/index` 输出稳定
- chunk locator 同时包含 entry 与持久 chunk 标识，可通过 MCP Resource 唯一读取来源与片段
- Alpha/Delta、Beta-only、no-hit 与 error query 返回可区分的 chunk 路径；
  错配 query 的相关性断言会失败
- chunk `no_hits`、`path_unavailable`、`search_error` 三种状态可区分
- 路径不可用与异常均回退文档级证据，并返回结构化 `chunk_degraded[reason]`
- 固定 evaluation 会递归读取所有可见 chunk/timeline/relation/entry locator；
  Resource 不可读或内容与 Tool 字段不一致时任务执行失败
- bridge 会验证 seed path 端点连续、候选全部邻接边覆盖、断连邻居对可从
  限定子图复算，以及 semantic score 的 entry/metadata locator、使用字段和
  重合计数；metadata Resource 的公开内容不含本机 `file_path`
- timeline 对五种支持字段做 FastMCP 预检；legacy alias 必须真实持久存在，
  仅 transient metadata 或损坏 frontmatter 时安全回退
- contrast 的全部可见维度必须有完整 provenance
- Phase B 新 Tool 响应及嵌套 relation evidence 不返回本机绝对路径；无
  `source_url` 时使用可读 entry Resource，而非 `file_path`
- `find_bridges` 公开 `subgraph_truncated`、实际 node/edge limits 和查询范围；
  截断时明确说明候选与负向结论不完整
- bridge、timeline 与 contrast 均公开可逐项核验的 provenance
- 三个 partial Tool 均返回 `implementation_level=partial`、`limitation_notes` 和 `evidence_sources`

三个探索 Tool 仍是 partial：`find_bridges` 只在最多 100 节点/300 边的
限定显式子图中计算，未接入 chunk 级桥接证据、全局中心性或语义关系边；
`timeline_of` 只精确引用可持久读取的结构化时间字段，未接入正文事件抽取、
时间语义解析或视频时间戳；`contrast` 未引入专门的 contrast 关系类型及
争议/补充/因果等高级语义建模。
