### 步骤 1：创建测试配置文件


## 完整工作流示例

### 示例：测试新的微信文章处理器改进

```powershell
# ========== 准备阶段 ==========

# 1. 备份生产数据（安全第一！）
.\scripts\backup-data.ps1 -Message "测试微信处理器改进前"

# 2. 确认测试环境配置
notepad .env.test  # 检查配置是否正确


# ========== 测试阶段 ==========

# 3. 在测试环境归档微信文章
.\scripts\run-test.ps1 archive "https://mp.weixin.qq.com/s/xxxxx"

# 4. 检查处理结果
.\scripts\run-test.ps1 show 1

# 5. 验证摘要质量
.\scripts\run-test.ps1 list


# ========== 验证阶段 ==========

# 6. 确认生产数据未受影响
python -m src.main stats  # 数据量应该不变


# ========== 清理阶段 ==========

# 7. （可选）清理测试数据
Remove-Item -Recurse -Force .data-test
```

## 提示与技巧

### 💡 技巧 1：使用 Git 分支 + 测试环境

```powershell
# 创建功能分支
git checkout -b feature/new-processor

# 在测试环境测试新功能
.\scripts\run-test.ps1 archive "https://example.com"

# 如果测试成功，切换到生产环境验证
python -m src.main archive "https://example.com"

# 提交代码
git add .
git commit -m "feat: 添加新内容处理器"
```

创建自定义脚本 `test-feature.ps1`:


## 故障排查

### 问题 1：测试数据出现在生产数据库

**检查**:
```powershell
# 验证环境变量
echo $env:DB_PATH  # 应该显示 .data-test/...
```

**解决**:
```powershell
# 重新加载 .env.test
Get-Content .env.test | ForEach-Object {
    if ($_ -match '^([^=]+)=(.*)$') {
        [Environment]::SetEnvironmentVariable($matches[1], $matches[2])
    }
}
```

### 问题 2：`run-test.ps1` 未找到配置文件

**检查**:
```powershell
# 确认文件存在
Test-Path .env.test  # 应该返回 True
```

**解决**:
```powershell
# 从模板创建
copy .env.test.example .env.test
```

### 问题 3：备份恢复后数据不完整

**检查备份信息**:
```powershell
# 查看备份详情
Get-Content .data-backup/20260216-150000/backup-info.json | ConvertFrom-Json
```

**验证数据**:
```powershell
# 检查数据库
python -m src.main stats

# 检查 Markdown 文件
Get-ChildItem -Recurse .data/vault | Measure-Object
```
