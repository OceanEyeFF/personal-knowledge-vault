# 测试环境快速开始

> 在 Windows 上使用 `.data-test/` 验证功能，不修改生产 `.data/`。

---

## 1. 准备本机配置

应用配置只写入 Git 忽略的 `config/local.yaml`。可以复制 `config/config.yaml` 再修改，也可以只写需要覆盖的字段：

```yaml
ai:
  llm:
    base_url: "<LLM endpoint>"
    api_key: "<本机密钥>"
    model: "<LLM 模型>"
  embedding:
    base_url: "<Embedding endpoint>"
    api_key: "<本机密钥>"
    model: "<Embedding 模型>"
    dim: "auto"
```

不要创建 `.env` 或 `.env.test` 来配置 Provider；不要打印密钥或其前缀。

## 2. 运行第一个隔离命令

在项目根目录执行：

```powershell
.\scripts\run-test.ps1 stats
```

`run-test.ps1` 会自动创建 `.data-test/` 并为子进程设置完整的数据路径，无需手工加载配置文件。默认模式运行 `python -m src.cli.commands <CLI-subcommand>`；pytest、Python 脚本等非 CLI 命令必须使用 `-Direct`，并通过 `-Command @("executable", "arg", ...)` 显式传入字符串数组。两种模式共享同一套路径隔离。

预期隔离路径：

```text
.data-test/db/knowledge_vault.db
.data-test/vault/
.data-test/vectors/
.data-test/logs/
.data-test/tmp/
```

## 3. 运行功能验证

```powershell
# 存储路径
.\scripts\run-test.ps1 archive "https://example.com"
.\scripts\run-test.ps1 list
.\scripts\run-test.ps1 show 1

# 消费路径
.\scripts\run-test.ps1 search "示例"

# 管理路径
.\scripts\run-test.ps1 stats
```

如果归档流程会访问真实 Provider，运行前确认 endpoint 可达、模型已加载，且测试 URL 有效。

## 4. 核对本地产物

```powershell
Get-ChildItem .data-test -Recurse
git status --short
```

通过标准：

- 数据库、Vault、向量索引和日志都位于 `.data-test/`。
- 脚本输出确认所有运行路径均在 `.data-test/`，且路径守卫未报错；AI 不读取 `.data/` 作对比。
- `config/local.yaml` 和 `.data-test/` 不出现在 Git 待提交列表中。

## 常用命令

| 操作 | 命令 |
|------|------|
| 查看测试统计 | `.\scripts\run-test.ps1 stats` |
| 归档网页 | `.\scripts\run-test.ps1 archive "URL"` |
| 搜索测试库 | `.\scripts\run-test.ps1 search "关键词"` |
| 列出测试条目 | `.\scripts\run-test.ps1 list` |
| 运行单元测试 | `.\scripts\run-test.ps1 -Direct -Command @("pytest", "tests/unit", "-q")` |
| 检查当前配置 | `.\scripts\run-test.ps1 config show` |

## 真实服务测试开关

只有明确需要运行 live pytest 时才设置：

```powershell
$env:PKV_RUN_LIVE = "1"
.\scripts\run-test.ps1 -Direct -Command @("pytest", "<live-test-path>", "-q")
Remove-Item Env:PKV_RUN_LIVE
```

Provider 参数仍从 `config/local.yaml` 读取。`PKV_RUN_LIVE` 只是运行开关，不用于保存密钥。

## 故障排查

### 数据写入了 `.data/`

立即停止可写命令，确认命令通过 `scripts/run-test.ps1` 运行。不要自动删除或覆盖 `.data/`；保留最小复现命令以便排查。

### Provider 配置不生效

核对 `config/local.yaml` 中的 `ai.llm.*` 和 `ai.embedding.*`：

```powershell
.\scripts\run-test.ps1 config show
```

只核对脱敏输出，不要显示或复制密钥。

### 更换了 Embedding 模型

endpoint、模型或维度改变后，原有 `.data-test/vectors` 不可直接复用，必须重建测试向量索引。不要清理 `.data/vectors`。
