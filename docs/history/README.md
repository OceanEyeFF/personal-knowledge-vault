# 历史文档说明

`docs/history/` 用于保留仍具追溯价值的历史材料，但它不是当前开发的默认入口。

## 当前保留范围

- `prompts/`：阶段主 Prompt 总览
- `milestones/`：关键里程碑完成报告与少量研究结论
- `issues/`：历史问题与迁移记录
- `discussions/`：对项目方向有启发价值的讨论
- `reviews/`：复盘与问题总结
- `references/`：少量长期参考资料

## 阅读建议

- 需要了解当前项目，应优先看 `docs/overview/`、`docs/modules/`、`docs/specs/`、`docs/operations/`
- 只有在需要追溯历史决策、旧路线演变或里程碑背景时，再进入 `docs/history/`
- 如果历史文档与当前核心文档冲突，以当前核心文档为准
