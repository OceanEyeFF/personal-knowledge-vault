## 项目背景

VCPToolBox (VCP) 是一个 AI 能力增强与进化中间层项目，虽然其整体定位与 PKV 不同（VCP 是 AI Agent 基础设施，PKV 是个人知识管理工具），但在 **知识/记忆管理** 和 **RAG 检索** 方面有值得借鉴的设计。

> **结论**: 详见 [存储与检索方案讨论 - 已达成的共识](./存储与检索方案讨论.md#已达成的共识)

### 当前 PKV 方案（已更新）

~~PRD 中描述的混合检索策略：~~
~~- BM25 粗排 + 向量精排~~

**更正**：BM25 和向量检索是**两种不同维度的工具**，不是粗排→精排关系：
- BM25（稀疏检索）：精确关键词、专有名词
- 向量 ANN（稠密检索）：语义相似度、概念查询
- PKV 暴露原子接口，AI 前端自主选择调用策略

### VCP 的 TagMemo "浪潮"算法

VCP 独创的高级 RAG 算法，核心特点：

#### 1. 四阶段处理流程

```
感应 (Sensing) → 分解 (Decomposition) → 扩张与召回 (Expansion) → 重塑与检索 (Retrieval)
```

#### 2. 核心模块

| 模块 | 功能 |
|------|------|
| EPA (Embedding Projection Analysis) | 计算逻辑深度、世界观门控、跨域共振检测 |
| 残差金字塔 (Residual Pyramid) | Gram-Schmidt 正交化，逐层剥离已解释能量，捕捉微弱语义信号 |
| 知识库管理器 | 核心标签召回、逻辑拉回、语义去重 |
| 偏振语义舵 (PSR) | 检测犹豫语义，引入负向对冲知识 |

#### 3. 关键创新

- **核心标签 vs 普通标签分级**：核心标签享有虚拟召回特权和权重加成 (1.2-1.4x)
- **词元组网（语义组）**：将关键词组织成逻辑组，整体触发
- **动态 Beta 公式**：`β = σ(L · log(1+R) - S · noise_penalty)`，根据意图动态调整
- **残差金字塔迭代**：直到 90% 语义能量被解释

### PKV 可借鉴的设计

#### ✅ 已采纳

1. **标签分级体系**
   - 核心标签：AI 辅助推荐 + AI 整理
   - 推断标签：普通权重，需通过相关性门控

2. **词元组 / 语义组概念**
   - 由 AI 动态学习生成
   - 整组触发机制

3. **检索接口原子化**
   - PKV 暴露原子搜索接口（BM25、向量、标签）
   - AI 前端决定调用策略

#### ⏸️ 保留不实现

- **残差金字塔**：预留可插拔接口，后续作为可替换算法模块

#### ❌ 不采纳

- 偏振语义舵（PKV 场景较少辩证查询）
- 20+ 魔法数字调参界面
- 完整的四阶段流程

## 讨论点二：存储方案 ✅ 已完成

> **结论**: 采用 **方案3（SQLite + hnswlib + jieba）**
> 详见 [存储与检索方案讨论](./存储与检索方案讨论.md#推荐方案方案3sqlite--独立-hnswlib--jieba-python-层分词)

### 最终决策

```
主存储：Markdown + YAML Front Matter（不变）
辅助存储：SQLite + hnswlib + jieba（新方案）
```

| 组件 | 技术选型 | 说明 |
|------|----------|------|
| 元数据 + 全文搜索 | **SQLite + FTS5** | 零配置、jieba 预分词支持中文 |
| 向量 ANN 检索 | **hnswlib** | 成熟 HNSW 实现、pip 安装、百万级无压力 |
| 中文分词 | **jieba** | 纯 Python、零依赖 |

### 被否决的方案

| 方案 | 否决原因 | 调研文档 |
|------|---------|---------|
| PostgreSQL + pgvector | 部署复杂，与"辅助存储"定位不匹配 | [存储与检索方案讨论](./存储与检索方案讨论.md) |
| LanceDB | 中文全文搜索不支持 | [LanceDB vs SQLite](./存储与检索方案讨论2-LanceDB-vs-SQLite.md) |
| KV 数据库 | 无法满足复杂查询需求 | [KV 数据库 vs SQLite](./存储与检索方案讨论3-KV数据库-vs-SQLite.md) |

| 讨论点 | 核心启发 | 状态 | 结论 |
|--------|----------|------|------|
| 检索方案 | 标签分级 + 语义组 + 接口原子化 | ✅ 完成 | AI 辅助标签、语义组动态学习、PKV 暴露原子接口 |
