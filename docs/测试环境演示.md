## 演示视频脚本

### 第 1 幕：初始化测试环境 (2 分钟)

```powershell
# ========== 场景：第一次使用测试环境 ==========

# 检查当前环境
Write-Host "✨ 步骤 1：检查生产环境状态" -ForegroundColor Cyan

# 输出示例：

# 总条目数: 42
# 数据库大小: 5.2 MB
# ...

Write-Host ""
Write-Host "✨ 步骤 2：创建测试环境配置" -ForegroundColor Cyan

# 从模板创建测试配置

    Copy-Item ".env.test.example" ".env.test"

Write-Host "测试环境配置:" -ForegroundColor Yellow
Get-Content ".env.test"

Write-Host ""
Write-Host "✨ 步骤 3：验证测试环境" -ForegroundColor Cyan
.\scripts\run-test.ps1 stats

# 输出示例：
# ========================================
#  测试环境模式 (Test Environment)
# ========================================
#   ✓ DB_PATH = .data-test/db/knowledge_vault.db
#   ✓ LOG_LEVEL = DEBUG
#
# [执行命令]
#   python -m src.main stats
#
# 知识库统计
# ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
# 总条目数: 0  👈 测试数据库是空的！
# ...
```

**关键点**:
- ✅ 生产数据库: 42 条数据（保持不变）
- ✅ 测试数据库: 0 条数据（全新环境）
- ✅ 完全隔离！

### 第 5 幕：清理测试环境 (1 分钟)

```powershell
# ========== 场景：测试完成后清理 ==========

Write-Host ""
Write-Host "🧹 清理测试环境" -ForegroundColor Cyan
Write-Host ""

# 查看测试数据大小
$test_size = (Get-ChildItem -Recurse .data-test | Measure-Object -Property Length -Sum).Sum / 1MB
Write-Host "测试数据大小: $([math]::Round($test_size, 2)) MB" -ForegroundColor Yellow

# 删除测试数据
Write-Host ""
Write-Host "删除测试数据..." -ForegroundColor Yellow
Remove-Item -Recurse -Force .data-test

Write-Host "  ✓ 测试数据已清理" -ForegroundColor Green
Write-Host ""

# 验证清理结果
if (!(Test-Path .data-test)) {
    Write-Host "✅ 清理完成！测试环境已移除" -ForegroundColor Green
}
```

**关键点**:
- ✅ 测试数据可以随时删除
- ✅ 不影响生产环境
- ✅ 保持工作目录整洁

## 完整演示脚本

将以上所有步骤整合到一个脚本 `demo-test-env.ps1`:

```powershell
# demo-test-env.ps1
# 测试环境完整演示脚本

Write-Host "========================================" -ForegroundColor Cyan
Write-Host " PKV 测试环境完整演示" -ForegroundColor Green
Write-Host "========================================" -ForegroundColor Cyan
Write-Host ""

# ========== 第 1 幕：初始化 ==========
Write-Host "第 1 幕：初始化测试环境" -ForegroundColor Magenta
Write-Host ""

Write-Host "1.1 检查生产环境状态" -ForegroundColor Yellow
python -m src.main stats | Select-String "总条目数"

Write-Host ""
Write-Host "1.2 创建测试配置" -ForegroundColor Yellow
if (!(Test-Path ".env.test")) {
    Copy-Item ".env.test.example" ".env.test"
    Write-Host "  ✓ 已创建 .env.test" -ForegroundColor Green
}

Write-Host ""
Write-Host "1.3 验证测试环境（应为空）" -ForegroundColor Yellow
.\scripts\run-test.ps1 stats | Select-String "总条目数"

Read-Host "`n按 Enter 继续到第 2 幕..."


# ========== 第 2 幕：测试功能 ==========
Write-Host ""
Write-Host "第 2 幕：在测试环境测试新功能" -ForegroundColor Magenta
Write-Host ""

Write-Host "请输入要测试归档的 URL（或按 Enter 跳过）:" -ForegroundColor Yellow
$test_url = Read-Host

if ($test_url) {
    Write-Host ""
    Write-Host "2.1 归档测试 URL" -ForegroundColor Yellow
    .\scripts\run-test.ps1 archive $test_url

    Write-Host ""
    Write-Host "2.2 查看测试数据库状态" -ForegroundColor Yellow
    .\scripts\run-test.ps1 stats | Select-String "总条目数"

    Write-Host ""
    Write-Host "2.3 查看归档的条目" -ForegroundColor Yellow
    .\scripts\run-test.ps1 show 1
} else {
    Write-Host "  已跳过归档测试" -ForegroundColor Gray
}

Read-Host "`n按 Enter 继续到第 3 幕..."


# ========== 第 3 幕：验证隔离 ==========
Write-Host ""
Write-Host "第 3 幕：验证生产环境未受影响" -ForegroundColor Magenta
Write-Host ""

Write-Host "3.1 检查生产环境状态" -ForegroundColor Yellow
python -m src.main stats | Select-String "总条目数"

Write-Host ""
Write-Host "✅ 验证通过：生产数据完全未受影响！" -ForegroundColor Green

Read-Host "`n按 Enter 继续到第 4 幕..."


# ========== 第 4 幕：备份与恢复 ==========
Write-Host ""
Write-Host "第 4 幕：数据备份与恢复" -ForegroundColor Magenta
Write-Host ""

Write-Host "4.1 备份生产数据" -ForegroundColor Yellow
.\scripts\backup-data.ps1 -Message "演示脚本自动备份"

Write-Host ""
Write-Host "4.2 列出最近的备份" -ForegroundColor Yellow
Get-ChildItem ".data-backup" -Directory |
    Sort-Object Name -Descending |
    Select-Object -First 3 |
    ForEach-Object {
        Write-Host "  • $($_.Name)" -ForegroundColor Cyan
    }

Write-Host ""
Write-Host "提示: 如需恢复，运行 .\scripts\restore-data.ps1" -ForegroundColor Yellow

Read-Host "`n按 Enter 继续到第 5 幕..."


# ========== 第 5 幕：清理 ==========
Write-Host ""
Write-Host "第 5 幕：清理测试环境" -ForegroundColor Magenta
Write-Host ""

Write-Host "是否清理测试数据？(Y/N)" -ForegroundColor Yellow
$cleanup = Read-Host

if ($cleanup -eq "Y" -or $cleanup -eq "y") {
    Write-Host ""
    Write-Host "5.1 删除测试数据" -ForegroundColor Yellow
    if (Test-Path .data-test) {
        Remove-Item -Recurse -Force .data-test
        Write-Host "  ✓ 测试数据已清理" -ForegroundColor Green
    } else {
        Write-Host "  • 测试数据不存在" -ForegroundColor Gray
    }
} else {
    Write-Host "  已保留测试数据" -ForegroundColor Gray
}


# ========== 结束 ==========
Write-Host ""
Write-Host "========================================" -ForegroundColor Cyan
Write-Host " 演示完成 ✓" -ForegroundColor Green
Write-Host "========================================" -ForegroundColor Cyan
Write-Host ""
Write-Host "总结:" -ForegroundColor Yellow
Write-Host "  ✅ 测试环境完全隔离" -ForegroundColor Green
Write-Host "  ✅ 生产数据安全无虞" -ForegroundColor Green
Write-Host "  ✅ 备份恢复流程顺畅" -ForegroundColor Green
Write-Host ""
Write-Host "下一步:" -ForegroundColor Yellow
Write-Host "  📖 阅读完整文档: docs/测试环境隔离指南.md" -ForegroundColor Cyan
Write-Host "  🚀 开始使用: .\scripts\run-test.ps1 <命令>" -ForegroundColor Cyan
Write-Host ""
```

**使用方式**:
```powershell
# 运行完整演示
.\demo-test-env.ps1
```

## 真实使用案例

### 案例 1：开发新的知乎回答处理器

```powershell
# 1. 备份（以防万一）
.\scripts\backup-data.ps1 -Message "开发知乎处理器前"

# 2. 测试归档知乎回答
.\scripts\run-test.ps1 archive "https://www.zhihu.com/question/xxx/answer/yyy"

# 3. 检查处理结果
.\scripts\run-test.ps1 show 1

# 4. 如果满意，在生产环境归档
python -m src.main archive "https://www.zhihu.com/question/xxx/answer/yyy"
```

### 案例 2：测试数据库 Schema 升级

```powershell
# 1. 备份生产数据
.\scripts\backup-data.ps1 -Message "Schema 升级前备份"

# 2. 在测试环境运行升级脚本
$env:DB_PATH = ".data-test/db/knowledge_vault.db"
python scripts/upgrade_schema.py

# 3. 验证升级结果
.\scripts\run-test.ps1 stats

# 4. 如果成功，在生产环境执行升级
# （谨慎！建议再次备份）
.\scripts\backup-data.ps1 -Message "生产环境升级前最终备份"
python scripts/upgrade_schema.py
```

### 案例 3：批量导入测试

```powershell
# 1. 准备测试 URL 列表
@"
https://example.com/article-1
https://example.com/article-2
https://example.com/article-3
"@ | Out-File test-urls.txt

# 2. 在测试环境批量归档
Get-Content test-urls.txt | ForEach-Object {
    Write-Host "归档: $_" -ForegroundColor Cyan
    .\scripts\run-test.ps1 archive $_
    Start-Sleep -Seconds 2  # 避免 API 限流
}

# 3. 检查测试结果
.\scripts\run-test.ps1 stats
.\scripts\run-test.ps1 list

# 4. 如果满意，清理测试数据并在生产环境执行
Remove-Item -Recurse -Force .data-test
# 然后在生产环境批量归档...
```
