## 系统要求

### 最低要求

| 组件 | 要求 | 说明 |
|------|------|------|
| **操作系统** | macOS / Linux / Windows (WSL2) | 推荐 macOS 或 Linux |
| **Python** | 3.11+ | 必须支持 type hints 和 async/await |
| **内存** | 4GB+ | 向量检索需要内存 |
| **磁盘空间** | 10GB+ | 用于存储 Markdown 文件和数据库 |
| **网络** | 稳定的互联网连接 | 需要调用 DeepSeek 和 OpenAI API |

### 推荐配置

- **Conda**: Miniconda 或 Anaconda（推荐，避免 Python 3.13 兼容性问题）
- **Python**: 3.11.x（⚠️ 不推荐 3.13，存在依赖兼容性问题）
- **内存**: 8GB+（处理大规模知识库时更流畅）
- **SSD**: 推荐使用 SSD 提升数据库性能

## 数据库初始化

### SQLite 数据库

项目使用 **SQLite** 作为元数据和索引的存储：

```bash

# 初始化数据库 Schema
python src/init_db.py
```

**预期输出**:

```

📂 数据库路径: .data/db/knowledge_vault.db
📊 已创建表: entries, tags, concepts, entry_tags, entry_concepts
🔍 已创建 FTS5 虚拟表: entries_fts
```

### hnswlib 向量索引

向量索引文件会在第一次添加内容时自动创建：

```bash
# 向量索引存储路径
.data/vectors/
├── embeddings.index   # HNSW 向量索引
└── embeddings.meta    # 元数据（ID 映射）
```

**索引配置** (伪代码):

```python
# src/retrieval/vector_store.py
class VectorStore:
    def __init__(self, dim=1536, max_elements=100000):
        self.dim = dim  # OpenAI Embedding 维度
        self.index = hnswlib.Index(space='cosine', dim=dim)
        self.index.init_index(
            max_elements=max_elements,
            ef_construction=200,  # 构建时搜索深度
            M=16                  # 每个节点的邻居数
        )
```

## 故障排查

### 问题 1: Python 3.13 兼容性问题 ⚠️

**症状**:

```
fatal error C1189: #error: "this header requires Py_BUILD_CORE define"
ERROR: Failed building wheel for lxml
ERROR: Failed building wheel for greenlet
```

**原因**: Python 3.13 太新，`lxml`、`greenlet`（playwright 依赖）等包还没有提供预编译版本

**推荐解决方案**: 使用 Conda 创建 Python 3.11 环境

```powershell
# Windows
.\scripts\setup-conda.ps1

# 或手动创建
conda create -n pkv-py311 python=3.11
conda activate pkv-py311
pip install -r requirements.txt
```

**或手动降级 Python**:
1. 卸载 Python 3.13
2. 安装 Python 3.11 (https://www.python.org/downloads/)
3. 重新运行安装脚本

### 问题 3: hnswlib 安装失败

**症状**:

```
ERROR: Failed building wheel for hnswlib
```

**解决方案**:

```bash
# macOS: 安装编译工具
brew install cmake

# Ubuntu/Debian
sudo apt-get install cmake build-essential

# 重新安装
pip install --no-cache-dir hnswlib
```

---

### 问题 4: SQLite FTS5 不可用

**症状**:

```
sqlite3.OperationalError: no such module: fts5
```

**解决方案**:

SQLite 3.35+ 默认支持 FTS5，如果报错说明版本过低：

```bash
# macOS: 使用 Homebrew 安装最新 SQLite
brew install sqlite3

# Ubuntu/Debian
sudo apt-get install sqlite3

# 验证版本
sqlite3 --version  # 应该 >= 3.35.0
```

---

### 问题 5: API 调用失败

**症状**:

```
Error: API key is invalid or expired
```

**解决方案**:

1. **检查 `.env` 文件是否正确加载**:

```python
# 调试代码
import os
from dotenv import load_dotenv

load_dotenv()
print("DeepSeek Key:", os.getenv("DEEPSEEK_API_KEY")[:10] + "...")
```

2. **验证 API Key 是否有效**:

```bash
# 测试 DeepSeek API
curl -X POST https://api.deepseek.com/v1/chat/completions \
  -H "Authorization: Bearer $DEEPSEEK_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"model":"deepseek-chat","messages":[{"role":"user","content":"Hello"}]}'
```

3. **检查网络代理设置** (如果在国内):

```bash
# 设置 HTTP 代理
export HTTP_PROXY=http://127.0.0.1:7890
export HTTPS_PROXY=http://127.0.0.1:7890
```

### 问题 7: 内存不足

**症状**:

```
MemoryError: Cannot allocate memory for HNSW index
```

**解决方案**:

1. **减小向量索引的 `max_elements`**:

```python
# src/retrieval/vector_store.py
self.index.init_index(
    max_elements=10000,  # 从 100000 减小到 10000
    ef_construction=200,
    M=16
)
```

2. **启用增量索引**:

```python
# 分批加载，避免一次性加载所有向量
for batch in batched_entries(batch_size=1000):
    vector_store.add_batch(batch)
```
