## 1. 使用说明

本清单只记录会影响当前 Phase 开发判断的 mismatch。

不记录的内容：

- 纯措辞差异
- 历史文档中已经明确降级为“历史参考”的早期路线表述
- 暂时无法从仓库静态内容直接验证的主观质量描述

优先级定义：

- `P0`：必须先修正，否则后续开发基线会继续漂移
- `P1`：应在 Phase 0 或紧随其后的文档同步中修正
- `P2`：记录为历史偏差，当前不阻塞主线

状态定义：

- `Open`：尚未修正
- `Mitigated`：已经通过真相源调整降低风险，但原始差异仍存在
- `Resolved`：差异已经被正式修正
